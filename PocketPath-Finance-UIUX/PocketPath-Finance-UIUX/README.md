# PocketPath — Personal Finance UI/UX Concept

PocketPath is a personal finance dashboard concept that helps people understand spending, follow simple budgets, and build better money habits.

## Included
- `figma-import/01-dashboard.svg` — overview dashboard
- `figma-import/02-transactions.svg` — transaction history
- `figma-import/03-budgets.svg` — category budget tracking
- `DESIGN-SYSTEM.md` — colors, type, spacing, components
- `DESIGN-CASE-STUDY.md` — problem, target audience, user journey, design decisions

## Import into Figma
1. Extract the ZIP file.
2. Open Figma and create a new Design file.
3. Drag an SVG from the `figma-import` folder onto the Figma canvas, or use **File → Place image**.
4. Ungroup imported elements as needed to edit individual vector pieces.
5. Use the design system notes to recreate reusable components and refine the prototype.

**Note:** This is a Figma-importable asset package, not a native `.fig` file. The SVG screens import as vector artwork; you may need to reorganize layers after import.
