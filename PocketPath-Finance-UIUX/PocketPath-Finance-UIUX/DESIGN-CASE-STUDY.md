# PocketPath — Mini UX Case Study

## Problem
Tracking money can feel intimidating when daily expenses, income, and saving goals are scattered across notes or apps. Users need a simple snapshot without financial jargon.

## Opportunity
Create an approachable dashboard that answers three questions quickly: How much do I have? Where has it gone? How much can I still spend?

## Target users
- Students managing a monthly allowance
- Early-career professionals tracking expenses
- People building a saving habit

## Primary user journey
1. Open Overview and scan balance, income, and spending.
2. Review recent transactions or search an expense.
3. Open Budgets to compare spending with category limits.
4. Use progress indicators to decide whether to adjust spending.

## Design decisions
- Summary cards put key metrics first.
- Consistent sidebar navigation connects the main sections.
- Progress bars and a ring chart reduce the need for mental arithmetic.
- Supportive copy avoids guilt-based money messaging.
- Forest green anchors the interface; lime highlights progress and primary actions.

## Questions to test
- Can a first-time user identify monthly spending in under five seconds?
- Can users spot a category that is close to its limit?
- Are income and expense entries easy to distinguish?
- Does the interface feel approachable?

## Future improvements
- Run usability tests with 5–8 people.
- Add empty, loading, and error states.
- Check keyboard navigation and color contrast.
- Explore a mobile layout and savings-goal flow.
